# U-Pool 1.0.1: Refuseless and validation

Validated on Windows x64 on 2026-10-27. Built on main commit
`3b97112217071eba77f852cccb7e87c101fdb377`, including the 1.0.0 API pool and
ChatGPT session-validation fixes. This is the main release line and supersedes
the separately published 0.9.1 maintenance build.

## Find Refuseless

1. Open a provider tab, such as **Claude Code**.
2. Select **+ Add provider → ! Refuseless**.
3. Enter your own API key.
4. Open **Advanced options → Load models** to retrieve the complete catalogue.
5. Search/select a main model and, for Claude, a small/fast model. Save the
   provider, then select its row to activate it.

The same preset is available for Codex, Hermes and OpenCode. Claude Desktop
retains its preview-only behavior. Compatible providers also support catalogue
discovery; manual model IDs remain available. Browser preview explicitly uses
sample data; real requests are made by the desktop backend.

Claude Code uses `https://api.refuseless.com` with bearer authentication.
Codex uses `https://api.refuseless.com/v1` with Responses; Hermes uses chat
completions and OpenCode uses `@ai-sdk/openai-compatible`.

## API examples

Set `REFUSELESS_API_KEY` in your shell. No API key is bundled in U-Pool.

```sh
curl https://api.refuseless.com/v1/models \
  -H "Authorization: Bearer $REFUSELESS_API_KEY"

curl https://api.refuseless.com/v1/messages \
  -H "Authorization: Bearer $REFUSELESS_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{"model":"glm-5.3-flash-abliterated","max_tokens":512,"messages":[{"role":"user","content":"Reply with OK only."}]}'
```

See [models](https://docs.refuseless.com/models) and
[client configuration](https://docs.refuseless.com/sdks).
