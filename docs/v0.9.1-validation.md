# U-Pool 0.9.1 validation

Validated on 2026-10-27 on Windows x64. This maintenance release starts at
`v0.9.0` (`f53aa811e8859179bf8ab03673c65a6cd91a3c7e`); it does not include the
separate 1.0.0 API pool. GitHub's latest release remains 1.0.0.

## Changes

- Refuseless presets for Claude Code, Claude Desktop (preview only), Codex,
  Hermes and OpenCode, with the requested exclamation mark icon.
- Advanced options can load the entire authenticated model catalogue, search it,
  and select the main model or Claude's small/fast model. Manual IDs still work.
- Catalogue discovery uses each adapter's endpoint/authentication, follows
  Anthropic pagination, preserves standard as well as abliterated models,
  and reports errors without substituting a static list or saving the draft.
- Requests run in the desktop backend. Browser preview uses explicitly labelled
  sample data and does not make authenticated provider requests.

## Live Refuseless checks

The authenticated catalogue returned HTTP 200 through the new U-Pool catalogue
reader, with these five models (all reporting a 1,048,576-token context):

| Model ID | Chat completion |
| --- | --- |
| `glm-5.3-abliterated` | HTTP 200, `OK` |
| `glm-5.3-flash-abliterated` | HTTP 200, `OK` |
| `deepseek-v4.1-flash-abliterated` | HTTP 200, `OK` |
| `deepseek-v4.1-flash-fast` | HTTP 200, `OK` |
| `minimax-m3.1-flash` | HTTP 200, `OK` |

The initial GLM 5.3 chat probe exhausted a 128-token budget on reasoning; a
512-token probe produced `OK`. This is why the catalogue does not imply a fixed
output budget for every model.

- Anthropic Messages: HTTP 200 and `OK` with GLM 5.3 Flash.
- Claude Code **2.1.311**, main GLM 5.3 preset: exit 0, `is_error: false`, result
  `OK`. Ran in a temporary configuration directory with tools, project settings,
  session persistence and MCP disabled. Real user configurations were not changed.
- Responses: HTTP 200 and output text `OK` with GLM 5.3 Flash.
- Messages streaming/tool call: HTTP 200; SSE contained `message_start`, a
  `tool_use` block for `echo`, an input delta containing `{"text":"OK"}`, and
  `message_stop`. The tool was not executed.

These are generation/protocol smoke checks, not a full coding-task benchmark.
Hermes, OpenCode and Codex were not run end to end. Claude Desktop remains the
existing preview-only adapter. A clean Windows installation was not tested.
