# U-Pool 0.6.0 — design

Status: approved 2026-07-31. This document is the contract every implementation
agent works from; interfaces named here are binding.

## Why

Three faults in 0.5.0, all confirmed against the author's own machine:

1. **The clean write destroys data.** `apply()` rebuilds `~/.claude/settings.json`
   and `~/.codex/config.toml` from the provider record alone. The live files hold
   far more than provider config — `enabledPlugins`, `extraKnownMarketplaces`,
   `theme`, `effortLevel`, `model` in the first; `[mcp_servers.*]`, `[plugins.*]`,
   `[projects.*]` trust levels, `notify`, `[windows]`, `[features]`,
   `[shell_environment_policy]` in the second. A switch wipes all of it.

2. **The CLIs read the registry, not just the files.** `HKCU\Environment` holds
   `OPENAI_API_KEY` and `codefast`, set by hand. Codex's `config.toml` says
   `env_key = "codefast"` and reads that key from the process environment, which
   U-Pool never touches — so switching provider changes the file and nothing else.

3. **`auth.json` accumulates.** It currently reads `{"codefast": "..."}`: a name
   an older build wrote and nothing removes.

## Scope

| # | Change |
|---|--------|
| 1 | Surgical file writes replace the clean write |
| 2 | OS-level environment variables (`HKCU\Environment`) become a managed target |
| 3 | `~/.codex/auth.json` written from scratch, ChatGPT login stashed and restored |
| 4 | Backup mode switch; backups become `<filename>.<ext>.backup` beside the original |
| 5 | Claude Desktop as a third tab — **UI only, writes nothing in 0.6.0** |
| 6 | Edit vs Add made unambiguous in the provider form |
| 7 | "CC Switch" wording removed |
| 8 | Version 0.5.0 → 0.6.0 |

## 1. `src/upool/winenv.py` (new)

Windows-only. Writes `HKCU\Environment`, then broadcasts `WM_SETTINGCHANGE`
(`SendMessageTimeoutW(HWND_BROADCAST, 0x1A, 0, "Environment", SMTO_ABORTIFHUNG, 5000)`)
so a newly launched process sees the change without a sign-out.

```python
@dataclass
class EnvResult:
    written: list[str] = field(default_factory=list)
    removed: list[str] = field(default_factory=list)
    adopted: list[str] = field(default_factory=list)  # pre-existing names taken over
    unsupported: bool = False
    error: str = ""

def supported() -> bool: ...
def read_all() -> dict[str, str]: ...
def read(name: str) -> str | None: ...
def owned(namespace: str) -> list[str]: ...
def preview(namespace: str, desired: dict[str, str]) -> dict[str, str | None]: ...
def apply(namespace: str, desired: dict[str, str]) -> EnvResult: ...
```

**Namespaces** — `"anthropic"` and `"openai"`. A namespace, not an app id, because
Claude Code and Claude Desktop share one set of variable names; there is no second
Anthropic namespace to give them.

**Ownership** — `~/.u-pool/env-owned.json` maps namespace → list of names U-Pool
currently sets. `apply` writes every name in `desired`, then deletes every name in
`owned[namespace]` that `desired` does not contain, then records the new list. A
name that is **not** in `owned[namespace]` is never deleted: the author's
`MINIMAX_CN_API_KEY`, `YUNWU_API_KEY` and `BLANKAPI_API_KEY` must survive.

**Adoption** — a name in `desired` that already exists in the registry and is not
yet owned is reported in `adopted`. Its original value reaches the backup written
by the caller before `apply` runs.

**Value type** — `REG_EXPAND_SZ` when the value contains `%`, otherwise `REG_SZ`.

**Never raises.** Registry trouble comes back as `EnvResult.error`; a switch must
not fail because a value would not write.

Off Windows every call is inert and returns `unsupported=True`.

## 2. Surgical file writes

`ApplyResult` gains two fields:

```python
env_written: list[str] = field(default_factory=list)
env_removed: list[str] = field(default_factory=list)
```

`Adapter` gains `env_namespace: str = ""` and `env_vars(provider) -> dict[str, str]`,
plus a shared `_apply_env(provider, result)` in the base class that snapshots the
values it is about to change, calls `winenv.apply`, and folds the outcome into the
result. `CLEAN_WRITE_TAG` and `archive_once` are removed.

### Claude Code — `~/.claude/settings.json`

Read the file, keep every key, and replace only:

- `env` — U-Pool owns this block whole. Rebuilt from the provider each switch, so a
  previous provider's variables cannot linger. Removed entirely for an official provider.
- `permissions.defaultMode` — set or deleted; sibling keys (`allow`, `deny`, `ask`) untouched.
- `permissions.skipDangerousModePermissionPrompt` — set or deleted.
- `enableAllProjectMcpServers` — set or deleted.

An empty `permissions` block left behind by deletion is dropped.
`enabledPlugins`, `extraKnownMarketplaces`, `theme`, `effortLevel`, `model`,
`hooks`, `statusLine` and everything else are preserved.

`removed` now reports only env names and toggle keys that went away.

Env namespace `anthropic`. `env_vars`:

| Variable | Source |
|---|---|
| `ANTHROPIC_BASE_URL` | `provider.base_url` (trailing slash stripped) |
| `ANTHROPIC_AUTH_TOKEN` **or** `ANTHROPIC_API_KEY` | `provider.api_key`, name per `auth_style`; the other name is not written, so ownership removes it |
| `ANTHROPIC_MODEL` | `provider.model` when set |
| `ANTHROPIC_SMALL_FAST_MODEL` | `provider.small_fast_model` when set |
| *(pass-through)* | every non-empty `provider.extra` entry |

An official provider yields `{}` — every owned Anthropic name is removed.

### Codex — `~/.codex/config.toml`

Read the document, keep every key and table, and replace only:

- `model_provider`, `model`
- the `TOP_LEVEL_EXTRA_KEYS` the provider supplies (deleted when it does not)
- `approval_policy` + `sandbox_mode` (the bypass pair), `web_search`
- `[model_providers]` — only the active provider's table survives; every other
  `[model_providers.*]` table is dropped and reported in `removed`

`[mcp_servers.*]`, `[plugins.*]`, `[projects.*]`, `notify`, `[windows]`,
`[features]`, `[desktop]`, `[marketplaces.*]`, `[shell_environment_policy]` are
preserved. An official provider drops `model_provider` and every provider table
and leaves the rest alone.

Env namespace `openai`. `env_vars`:

| Variable | Source |
|---|---|
| `provider.env_key` | `provider.api_key` — this is what makes `env_key = "codefast"` work |
| `OPENAI_BASE_URL` | `provider.base_url` |

Official → `{}`.

### Codex — `~/.codex/auth.json`

Written from scratch, as requested. Exactly:

- custom provider, `env_key == "OPENAI_API_KEY"` → `{"OPENAI_API_KEY": "<key>"}`
- custom provider, any other `env_key` → `{}` — the key now reaches the CLI through
  the registry, so the old "set that variable yourself" warning is deleted
- official provider → the stashed ChatGPT login, or `{}` when there is none

**Login stash.** Before the first clean write, if the file holds anything other
than `OPENAI_API_KEY` (a ChatGPT login: `tokens`, `last_refresh`, `account_id`),
the whole original is copied to `~/.u-pool/codex-login.json`. Switching to the
official provider restores it verbatim. Without this, "write from scratch" would
destroy a login U-Pool cannot recreate.

### Claude Desktop — nothing

`ClaudeDesktopAdapter`: `live_files() -> []`, `env_namespace = ""`,
`import_live() -> None`, `health_target` identical to Claude Code so Test still
works. `apply()` writes nothing and returns a single warning:

> Claude Desktop is preview-only in 0.6.0 — your choice was recorded, but no
> configuration was written.

`%APPDATA%\Claude\claude_desktop_config.json` is never opened.

## 3. Backups

`~/.u-pool/settings.json` gains `"backup_enabled": True`.

`backup.py` is rewritten around a single convention: **one current copy beside the
original**, named `<filename>.backup` — `settings.json.backup`,
`config.toml.backup`, `auth.json.backup`. Overwritten on every change.

```python
def enabled() -> bool: ...
def sidecar(source: Path) -> Path | None:   # source.with_name(source.name + ".backup")
def env_snapshot(values: dict[str, str | None]) -> Path | None:
    # ~/.u-pool/backups/environment.backup.json — registry values cannot sit
    # beside anything, so they keep the app-home location.
```

Both return `None` and touch nothing when the switch is off. `snapshot`,
`archive_once`, `prune`, `list_backups`, `KEEP_PER_FILE` and `ARCHIVE_SUFFIX` are
deleted along with the rolling scheme.

The Settings panel gets the switch, a one-line explanation and the existing
Backups folder row. **No backup browser or restore screen in 0.6.0.**

## 4. Registry and store

```python
APP_CLAUDE = "claude"
APP_CLAUDE_DESKTOP = "claude_desktop"
APP_CODEX = "codex"
SUPPORTED_APPS = (APP_CLAUDE, APP_CLAUDE_DESKTOP, APP_CODEX)
```

`validate()` treats `claude_desktop` exactly like `claude` (same `auth_style`
check). `adapters._ADAPTERS` gains the entry between Claude Code and Codex, so tab
order is Claude Code · Claude Desktop · Codex. `store.OFFICIAL_SEEDS` gains a
Claude Desktop entry; its slot bootstraps with that entry alone (`import_live`
returns `None`).

## 5. API and bridge

`api.py`:

- `_settings()` gains `backup_enabled`
- `set_backup_enabled(enabled: bool) -> dict` — new endpoint
- `switch_provider` returns `env_written` and `env_removed`
- `environment(app: str) -> dict` — new endpoint:
  `{"supported": bool, "namespace": str, "vars": [{"name", "value_masked", "owned"}]}`
- `open_env_settings() -> str` — `rundll32 sysdm.cpl,EditEnvironmentVariables`

`ui/lib/types.ts`:

```ts
export type AppId = "claude" | "claude_desktop" | "codex";
// AppSettings   += backup_enabled: boolean
// SwitchResult  += env_written: string[]; env_removed: string[]
export interface EnvInfo {
  supported: boolean;
  namespace: string;
  vars: { name: string; value_masked: string; owned: boolean }[];
}
```

`bridge.ts` and `mock.ts` follow.

## 6. UI

**Header** — three tabs. `claude` keeps `ClaudeGlyph`; `codex` keeps `OpenAILogo`;
`claude_desktop` gets a new `ClaudeDesktopGlyph` in `icons.tsx` (the Claude
starburst inside a monitor outline). The segmented control has to stay inside the
760px header — verify at that width.

**Claude Desktop tab** — a persistent notice above the list:

> Preview — U-Pool does not write Claude Desktop's configuration yet. Providers
> you add here are saved and will apply once support lands.

**ProviderForm**

- takes an explicit `mode: "add" | "edit"` prop; `editing` is derived from it and
  never from `initial?.id`
- bottom primary button: `Saving…` / **`Save changes`** / `Add provider`
- `page.tsx` renders `<ProviderForm key={view.provider?.id ?? "new"} … />` so the
  form state cannot survive from one provider to the next
- `"CC Switch style · N templates"` → `"N templates"`
- `"Template from CC Switch-style presets. …"` → `"Template ready — URL and model
  are filled. Paste your API key and save. Switch to Custom for a blank form."`

**SettingsPanel**

- new **Backups** section: the switch, the `<filename>.backup` explanation, the
  folder row
- new **Windows environment** section: the variable names U-Pool manages for the
  active app with masked values, and a button that opens the Windows editor
- the pre-0.5.0 paragraph about ten rolling backups is replaced

**Toast after a switch** — names the env variables written and removed alongside
the files.

## 7. Version and docs

`src/upool/__init__.py`, `pyproject.toml`, `ui/package.json` → `0.6.0`.
`README.md`: version badge, the backups row in the feature table, and the
"clean write" section rewritten to describe surgical writes plus the registry.

## 8. Tests

Run with `pytest --basetemp=<writable dir>`; the suite errors in fixture setup
without it.

- `tests/test_winenv.py` (new) — ownership, adoption, deletion limited to owned
  names, namespace isolation. Redirect the registry key through a fixture the way
  `conftest.py` already redirects `autostart.RUN_KEY`; skip off Windows.
- `tests/test_backup.py` (new) — sidecar naming and placement, no-op when off.
- `test_claude_adapter.py` — a settings.json carrying `enabledPlugins`, `theme`,
  `model` and `permissions.allow` survives a switch intact; `env` is rebuilt, not merged.
- `test_codex_adapter.py` — `[mcp_servers.*]`, `[projects.*]` and `notify` survive;
  stale provider tables go; auth.json is exactly the clean write; the login stash
  round-trips.
- `test_models.py`, `test_store.py`, `test_settings.py`, `test_api.py` — the third
  app, `backup_enabled`, the new endpoints.
- `conftest.py` — redirect `winenv`'s registry key and owned-file into `tmp_path`.

## Accepted trade-offs

- **Claude Code and Claude Desktop share the Anthropic registry variables.**
  Claude Desktop has no other lever. It writes nothing in 0.6.0, so the collision
  is inert today; when writing lands, Claude Code's `settings.json` `env` block
  overrides the process environment, so the CLI keeps its own provider.
- **Claude Desktop does not officially honour `ANTHROPIC_BASE_URL`.** Effect will
  be limited to Cowork / local code sessions that inherit the environment.
- **Stale `[model_providers.*]` tables are removed** even if hand-written. That is
  the pile-up the release is meant to fix.
